# Roadmap

PlainJot grows by making local Markdown more useful, not by becoming a workspace suite.

## v0.1 — Foundation

- Core Markdown notes
- Shared web interface
- Native macOS application

## v0.2 — Tasks and agents

- YAML-frontmatter tasks
- Agent Inbox
- Native filesystem watcher

## v0.3 — Agent workflows

- Stable CLI
- Improved installation and release archives
- Refined human/agent handoff patterns

## v0.4 — MCP

- Small MCP server over PlainJot Core
- Operations for notes, tasks, completion, listing, and search

## v1.0 — Stable local notebook

- Stable file format and CLI contract
- Signed and notarized macOS releases
- Reliable agent-native local notebook workflows

Priorities, deadlines, subtasks, advanced tags, collaboration, and cloud sync are intentionally outside the near-term roadmap.
